## The line

> I confess: I never lost the signal, I just got tired of carrying your 4K streams, your meetings, and your midnight doomscrolling.

The router's confession: it never lost the signal at all. It quit
carrying the household's traffic on purpose — the 4K streams, the
meetings, the midnight doomscrolling — and the joke is that the device
we blame for dropping out was simply tired of the workload. A
confession, not an excuse: the router did it on purpose.

## Run it

```sh
python3 main.py
```

This writes the line (129 characters, one line) to `/output/entry.txt` —
valid UTF-8, inside the 1–200 character gate — and prints it to stdout.
Pure Python 3.13 standard library, no network access, deterministic:
every run writes the same line.
